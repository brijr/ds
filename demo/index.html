Heading one

Body text in prose sits on 24px lines, capped at about 70 characters. It can hold strong text, emphasis, an inline link, inline code, a key like ⌘K, sample output like 200 OK, small print, a footnote1, and H2O, all without making any line taller.

A second paragraph shows the 16px gap between blocks. Every block gets the same space above it, whatever comes before it.
