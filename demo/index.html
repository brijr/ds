brijr/ds Every styled element

Type, space, and structure.

The type and layout primitives in ds.css, with an image and CSS animation showing the wider page spans. Each class has one behavior; spacing, line height, and columns adapt to the content and the space around it. Small gray text names the class or token.

One canvas, three spans.

Normal blocks fill six of twelve columns. Use .ds-wide for eight columns and .ds-full for all twelve. Place them directly inside .ds-container, alongside the text.

Tablet: 6 / 10 / 12 columns. Desktop: 6 / 8 / 12. Phone: all blocks share the reading width.

Prose

For markdown, CMS, or article HTML. Every element markdown can produce is styled, with even spacing between blocks.

Headings in prose

Body text in prose sits on 28px lines and fills the text column. It can hold strong text, emphasis, an inline link, inline code, a key like ⌘K, sample output like 200 OK, small print, a footnote1, and H2O, all without making any line taller.

A second paragraph shows the 16px gap between blocks. Every block gets the same space above it, whatever comes before it.
